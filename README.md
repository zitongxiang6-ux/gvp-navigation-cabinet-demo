# GVP 导航与配电箱增强交互 Demo

## 迭代基线

本目录是 REQ-2026-001 至 REQ-2026-004 的唯一当前 Demo 基线。后续同一组需求的交互调整默认直接在本目录继续修改，不另建平行 Demo；只有用户明确要求保留独立版本时才复制新目录。详细约束见 [BASELINE.md](BASELINE.md)。

## 覆盖范围

- Demo 展示层暂时隐藏左侧【首页】和【导航】两个入口；对应页面、路由和实现代码全部保留，可在后续评审需要时恢复。
- REQ-2026-001：导航只保留组件视图；主导航保留独立“配电箱设备查询”，删除“设备功能”菜单、路由页面及专属实现。新查询页左侧区域树以“天府校区”为根节点，校区和楼栋均可展开/收起，并与所选区域下的配电箱/未分类收窄后左右并排；右侧顶部仅保留状态、设备备注、设备类型、型号、所属 IP 五个即时筛选字段，状态只包含在线和离线；设备明细表格字段与设备管理一致，左侧提供本页全选与行复选框，底部提供分页；右上角导出当前筛选后的全部 11 列明细，不受当前页和勾选状态限制。
- REQ-2026-002：配电箱及设备关联由其他平台维护并同步；GVP 只读消费同步结果，用于独立配电箱设备查询的区域/配电箱即时筛选、未分类、在线设备数/设备总数、带复选框和分页的设备明细及筛选结果导出，以及设备管理的只读展示、筛选和导出；不提供配电箱维护或关联写操作。
- REQ-2026-003：历史记录保持三列，将“设备故障”类型改为“设备离线”，并在离线消息末尾追加 IP 地址；消息中的配电箱名称使用其配置颜色，仅改变字体颜色，不增加图标。
- REQ-2026-004：设备管理右上角不显示“配电箱”入口，不提供清除、新建、管理、选择等写操作；保留配电箱下拉自动筛选、列表只读展示，并在列表和导出中增加楼层节点字段。

## 启动方式

推荐直接双击 `启动Demo.cmd`。脚本会在后台启动本地服务并自动打开浏览器；重复执行不会重复创建服务。

也可以在 Demo 目录中执行：

```powershell
.\start-demo.ps1 -OpenBrowser
```

或在项目根目录执行：

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory "workspace\demo\REQ-2026-001-004-gvp-navigation-cabinet"
```

然后访问：`http://127.0.0.1:4173/?v=20260909-cabinet-filter-trim#cabinet-functions`

如需关闭后台服务，在 Demo 目录执行：

```powershell
.\stop-demo.ps1
```

## 配电箱设备查询保护基线

- “设备功能”菜单、路由页面和专属实现均不保留；访问旧 `#device-functions` 地址自动进入【配电箱设备查询】。
- 配电箱设备查询的区域树根节点名称为“天府校区”；点击校区或楼栋箭头只切换展开/收起，点击名称仍选择对应区域并自动筛选。区域树与配电箱选择左右并排；右侧直接展示设备明细表格，字段与设备管理一致，不提供控制、编辑或关系写操作。
- 查询页顶部第一个下拉框仅包含状态、设备备注、设备类型、型号、所属 IP；不再提供协议、产品名、设备地址、连接方式和楼层节点筛选。状态仅显示在线和离线，状态与设备类型显示“全部”及对应值的下拉框，其他字段显示文本输入框。选择或输入后立即筛选，清空后立即恢复当前区域与配电箱的全部明细。
- 明细列表第一列为复选框：表头复选框选择/取消当前页全部行，行复选框选择单条数据；翻页时保留当前结果集内的勾选，区域、配电箱或顶部筛选条件变化时回到第一页并清空旧选择。列表底部显示分页，默认每页 10 条。
- 查询页右上角显示“导出”按钮；点击后导出当前区域、配电箱和顶部筛选条件共同命中的全部数据，不受当前页和勾选状态限制；CSV 字段顺序与表格数据列一致：设备备注、设备类型、状态、协议、型号、产品名、设备地址、连接方式、所属 IP、配电箱、楼层节点。

## 技术说明

- 零依赖静态 HTML、CSS、JavaScript，不连接真实接口。
- 所有数据均为脱敏 Mock 数据，只保存在当前页面内存中；刷新页面恢复初始状态。
- 配电箱和设备/功能关联均为外部同步结果的 Mock 快照；Demo 不提供配电箱主数据或关系写入口。
- 配电箱设备查询与设备管理使用同一份设备 Mock 数据；独立“设备功能”页面已删除。
- 所有标准列表筛选自动生效，不增加查询或重置按钮。
- 首页和导航仅通过 `is-temporarily-hidden` 隐藏入口；恢复时移除该类名即可，不需要恢复页面代码。
