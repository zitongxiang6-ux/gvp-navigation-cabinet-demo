# GVP 导航与配电箱增强交互 Demo

## 迭代基线

本目录是 REQ-2026-001 至 REQ-2026-004 的唯一当前 Demo 基线。后续同一组需求的交互调整默认直接在本目录继续修改，不另建平行 Demo；只有用户明确要求保留独立版本时才复制新目录。详细约束见 [BASELINE.md](BASELINE.md)。

## 覆盖范围

- Demo 展示层暂时隐藏左侧【首页】和【导航】两个入口；对应页面、路由和实现代码全部保留，可在后续评审需要时恢复。
- REQ-2026-001：导航只保留组件视图；取消独立“配电箱设备列表”菜单，将配电箱分组能力合并到已有“设备功能”。设备功能保留截图已有三个筛选、七个操作按钮、复选框和全部原字段；左侧新增配电箱/未分类分组，“配电箱”位于“所属页面”右侧，功能名称、设备备注、设备名称提供上下排序。
- REQ-2026-002：配电箱及设备/功能关联由其他平台维护并同步；GVP 只读消费同步结果，用于设备功能平铺分组、未分类、在线功能点数/总功能点数、列表联动和配电箱字段，不提供配电箱维护或关联写操作。
- REQ-2026-003：历史记录保持三列，只增强设备故障的消息内容，在原故障内容末尾追加 IP 地址；消息中的配电箱名称使用其配置颜色，仅改变字体颜色，不增加图标。
- REQ-2026-004：设备管理右上角不显示“配电箱”入口，不提供清除、新建、管理、选择等写操作；保留配电箱下拉自动筛选、表格末列只读展示和设备导出配电箱字段。

## 启动方式

推荐直接双击 `启动Demo.cmd`。脚本会在后台启动本地服务并自动打开浏览器；重复执行不会重复创建服务。

也可以在 Demo 目录中执行：

```powershell
.\start-demo.ps1 -OpenBrowser
```

或在项目根目录执行：

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory "workspace\demo\REQ-2026-001-004-gvp-navigation-cabinet"
```

然后访问：`http://127.0.0.1:4173/?v=20260828-device-function-sort-cabinet-order#device-functions`

如需关闭后台服务，在 Demo 目录执行：

```powershell
.\stop-demo.ps1
```

## 设备功能保护基线

- 筛选控件名称和顺序保持为“功能名称、搜索、所有”。
- 操作按钮名称和顺序保持为“绑定回路、功率、测试、编辑、移除、标签、导出”。
- 复选框和原表格字段保持为：功能名称、功能类型、状态、所属页面、设备备注、设备名称、楼层节点、功率、总使用寿命、总开合次数、运行时间、已开合次数、绑定回路数、描述。
- “功能名称、设备备注、设备名称”右侧显示上下排序入口；首次点击按升序排列，再次点击切换为降序，切换排序时回到第 1 页。
- “配电箱”新增在“所属页面”右侧；已有“状态”列直接复用，不重复新增。
- 配电箱字段只展示外部同步结果，任何设备功能按钮都不能写入配电箱或关联关系。

## 技术说明

- 零依赖静态 HTML、CSS、JavaScript，不连接真实接口。
- 所有数据均为脱敏 Mock 数据，只保存在当前页面内存中；刷新页面恢复初始状态。
- 配电箱和设备/功能关联均为外部同步结果的 Mock 快照；Demo 不提供配电箱主数据或关系写入口。
- 设备功能使用原组件 Mock 数据模拟功能点；已有按钮在 Demo 中保留名称、顺序和入口，配电箱新增项不改变其职责。
- 所有标准列表筛选自动生效，不增加查询或重置按钮。
- 首页和导航仅通过 `is-temporarily-hidden` 隐藏入口；恢复时移除该类名即可，不需要恢复页面代码。
