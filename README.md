## 启动方式

推荐直接双击 `启动Demo.cmd`。脚本会在后台启动本地服务并自动打开浏览器；重复执行不会重复创建服务。

也可以在 Demo 目录中执行：

```powershell
.\start-demo.ps1 -OpenBrowser
```

或在项目根目录执行：

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory "workspace\demo\REQ-2026-001-004-gvp-navigation-cabinet"
```

然后访问：`http://127.0.0.1:4173/?v=20261110-energy-detail-analysis-labels-v44#overview`

如需关闭后台服务，在 Demo 目录执行：

```powershell
.\stop-demo.ps1
```

## 配电箱设备查询保护基线

- “设备功能”菜单、路由页面和专属实现均不保留；访问旧 `#device-functions` 地址自动进入【配电箱设备查询】。
- 配电箱设备查询的区域树根节点名称为“天府校区”；点击校区或楼栋箭头只切换展开/收起，点击名称仍选择对应区域并自动筛选。区域树与配电箱选择左右并排；右侧直接展示设备明细表格，字段与设备管理一致，不提供控制、编辑或关系写操作。
- 查询页顶部第一个下拉框仅包含状态、设备备注、设备类型、型号、所属 IP；不再提供协议、产品名、设备地址、连接方式和楼层节点筛选。状态仅显示在线和离线，状态与设备类型显示“全部”及对应值的下拉框，其他字段显示文本输入框。选择或输入后立即筛选，清空后立即恢复当前区域与配电箱的全部明细。
- 明细列表第一列为复选框：表头复选框选择/取消当前页全部行，行复选框选择单条数据；翻页时保留当前结果集内的勾选，区域、配电箱或顶部筛选条件变化时回到第一页并清空旧选择。列表底部显示分页，默认每页 10 条。
- 查询页右上角显示“导出”按钮；点击后导出当前区域、配电箱和顶部筛选条件共同命中的全部数据，不受当前页和勾选状态限制；CSV 字段顺序与表格数据列一致：设备备注、设备类型、状态、协议、型号、产品名、设备地址、连接方式、所属 IP、配电箱、楼层节点。

## Demo 假设

下列内容仅为评审演示口径，尚待产品与研发确认：

- 首页能耗数值、分类占比和历史趋势均为脱敏 Mock 数据；正式接口字段、刷新频率、缺失值、精度和统计边界待确认。
- “当月累计电量”和“当年累计电量”按自然月、自然年展示；环比采用 `(当月用电量 - 上月用电量) / 上月用电量`，同比采用 `(当月用电量 - 去年同月用电量) / 去年同月用电量`，仅用于本次交互评审。
- 外部同步协议、主键、频率、失败和延迟处理，以及配电箱停用或关系删除后的显示与恢复规则。
- 宽表格使用内容区横向滚动并固定右侧操作列；是否继续冻结设备备注、相别等左侧关键列尚待确认。
- 独立查询页的区域与配电箱归属来自 Demo 中设备关系数据；正式区域—配电箱数据契约待确认。
- 设备状态刷新频率待确认。
- 安科瑞和众源来源的稳定唯一标识、单相/三相标识、各相及总值字段、单位、互感器变比、时间戳和质量标识仍待研发数据契约确认；当前可见页的 A/B/C 相位及单相字段均为脱敏 Mock，用于验证展示结构，不替代正式设备点位契约。
- 新增候选按当前有效统计关系判断：设备只添加部分分相功能点时仍可继续添加，已添加项只读且只保存本次新选项；设备按整表、全部分相功能点或空开回路完整添加后退出新增候选。部分分相续加不允许在“添加”中直接切换整表，避免整表与分相重复生效；模式转换统一从主列表编辑进入。
- 分类变更按保存时间切分新旧版本；区域、用电类型、整表/分相模式变化都保留来源快照、历史区间和区间能耗。每条历史记录汇总设备在一个生效区间内产生的能耗：分相模式合计该设备各功能点，整表模式按整表统计；变更后另起新区间，已结束区间不按新配置回算。Demo 区间能耗使用脱敏 Mock 快照，正式增量算法及采样边界仍待数据契约确认。
- 详情中的当前累计能耗、本月用电、日均用电和趋势序列均为脱敏 Mock 分析数据；本月用电和日均用电按当前生效的分相/整表及其区域、用电类型展示，正式统计周期、当前区间增量口径和趋势聚合粒度仍待数据契约确认。
- 首页近7天、近30天趋势使用由所选月份月度 Mock 数据拆分得到的日级演示数据，近12月使用月度 Mock 数据；正式日级采样、聚合和缺数处理仍待数据契约确认。
- 当前可见页的 35 条回路、初始归属及批量保存均为脱敏 Mock；保存只影响本页内存，不写入原隐藏页面数据，刷新页面恢复。
- 简化方案对比页的 A相、B相、C相为本次评审演示填充值，仅用于验证列表和详情字段展示，不替代正式设备功能点或数据契约中的相位字段。

## 技术说明

- 零依赖静态 HTML、CSS、JavaScript，不连接真实接口。
- 所有数据均为脱敏 Mock 数据，只保存在当前页面内存中；刷新页面恢复初始状态。
- 配电箱和设备/功能关联均为外部同步结果的 Mock 快照；Demo 不提供配电箱主数据或关系写入口。
- 配电箱设备查询与设备管理使用同一份设备 Mock 数据；独立“设备功能”页面已删除。
- 所有标准列表筛选自动生效，不增加查询或重置按钮。
- 首页入口已恢复；导航入口仍通过 `is-temporarily-hidden` 隐藏，不需要恢复页面代码。
- 能源统计分类使用独立 Mock 数据；候选池包含 5 台新增电表、5 个新增空开，以及可继续补充分相的 A 区总配电表。添加、编辑以及用电类型添加、编辑、启禁用和删除只修改当前浏览器内存，刷新页面恢复。
- 当前可见能源统计分类页使用独立 Mock 行数据，从 8 台三相电表、3 台单相电表和 8 个空开生成 35 行；第一页按 3 行三相、3 行单相、4 行空开均衡展示。单条与批量分配分别只改区域或用电类型，不会改动原隐藏页面的数据和交互。三相按相别展示分相指标，设备总有功/无功功率、总有功/无功电能及视在功率进入详情展示。
