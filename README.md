# GVP 导航与配电箱增强交互 Demo

## 迭代基线

本目录是 REQ-2026-001 至 REQ-2026-004 的唯一当前 Demo 基线。后续同一组需求的交互调整默认直接在本目录继续修改，不另建平行 Demo；只有用户明确要求保留独立版本时才复制新目录。详细约束见 [BASELINE.md](BASELINE.md)。

## 覆盖范围

- REQ-2026-001：导航“组件视图 / 列表视图”切换；两种视图均提供全开/全关；列表每行一个组件，“控制”直接打开对应类型的小组件，“编辑”与组件视图编辑入口统一进入完整组件编辑页。
- REQ-2026-002：设备管理提供清除、新建、管理、选择四项配电箱操作；新增弹窗使用行内软盘图标保存且底部仅关闭，管理列表提供编辑、删除、新增图标并支持在末尾追加可编辑行。
- REQ-2026-003：历史记录保持三列，只增强设备故障的消息内容，在原故障内容末尾追加 IP 地址；消息中的配电箱名称使用其配置颜色，仅改变字体颜色，不增加图标。
- REQ-2026-004：配电箱关系操作合并到设备管理唯一“配电箱”按钮；设备表格最后新增“配电箱”列，名称使用其配置颜色且不增加图标；查询条件增加配电箱下拉并在选择后自动筛选，设备导出增加配电箱字段。

## 启动方式

推荐直接双击 `启动Demo.cmd`。脚本会在后台启动本地服务并自动打开浏览器；重复执行不会重复创建服务。

也可以在 Demo 目录中手动执行：

```powershell
.\start-demo.ps1 -OpenBrowser
```

或在项目根目录执行原始命令：

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory "workspace\demo\REQ-2026-001-004-gvp-navigation-cabinet"
```

然后访问：`http://127.0.0.1:4173/?v=20260826-cabinet-filter#navigation`

如需关闭后台服务，在 Demo 目录执行：

```powershell
.\stop-demo.ps1
```

## 页面入口

| 页面 | 地址 | 主要可操作内容 |
|---|---|---|
| 导航 | `#navigation` | 截图式组件视图、两种视图全开/全关、自动筛选、分页、差异化小组件控制弹层、统一整页编辑；列表不显示重复标题和查询/重置按钮 |
| 设备管理 | `#devices` | 保留参考页的筛选和分页；新增配电箱下拉并在选择后自动筛选；列表最后一列以配置颜色显示当前有效配电箱名称，不增加颜色图标；导出包含配电箱字段；新增弹窗行内保存、底部关闭，管理列表可编辑、删除并在末尾追加新行 |
| 历史记录 | `#history` | 类型/日期选择后自动筛选、分页、导出、清空 Demo 数据；设备故障消息末尾显示 IP 地址，配电箱名称使用其配置颜色且无图标；不显示重复标题、说明条或查询/重置按钮 |

左侧栏底部的说明按钮可查看已确认规则和 Demo 假设，也可恢复全部初始数据。

## 技术说明

- 零依赖静态 HTML、CSS、JavaScript，不连接真实接口。
- 所有数据均为脱敏 Mock 数据，只保存在当前页面内存中；刷新页面恢复初始状态。
- Demo 中删除配电箱会同步清除当前内存里的设备关联；正式删除、停用和历史追溯规则仍需产品与研发确认。
- 导航 Demo 覆盖开关、RGB、色温、空调、窗帘和风机六类代表性控制；正式产品应直接复用每个现有组件的控制定义，而不是依赖 Demo 中的固定类型清单。
- 设备导出按当前筛选结果导出，并在末列包含配电箱名称；历史导出仍为“类型、日期和时间、消息内容”三列。

## 验证记录

- `data.js`、`app.js` 已通过 Node.js 语法检查。
- `start-demo.ps1`、`stop-demo.ps1` 已通过 PowerShell 语法检查。
- 本地 HTTP 服务下 `index.html`、CSS、JavaScript 和 README 均返回 200。
- 导航 Mock 数据已校验 31 个组件、6 类代表性控制及会议室组件视图数据；列表控制弹层直接复用对应小组件，整页编辑入口在两种视图保持一致。
- 设备管理可见 Mock 数据逐行采用参考图中的设备备注、类型、状态、协议、地址、连接方式和所属 IP；配电箱下拉仅列出启用配电箱，选择后立即筛选且不增加查询/重置按钮；列表最后显示当前唯一且启用的配电箱，名称文字使用该配电箱配置颜色且不增加颜色图标；未配置、停用或多归属时留空；设备导出末列包含配电箱名称。
- 新增配电箱以行内软盘图标保存，保存后进入管理列表；弹窗底部为“关闭”。管理列表的加号会在末尾追加一条可编辑行，保存后立即进入列表。
- 历史记录页不显示内容区重复标题、说明条或查询/重置按钮；类型和日期选中后自动筛选。
- 每条设备故障记录在原故障内容末尾显示脱敏 Mock IP 地址；消息中的配电箱名称文字与设备列表使用同一配置颜色且不增加颜色图标；楼栋、房间或配电箱任一缺失时直接沿用原故障字段并追加 IP，不显示“未配置”且不留空层级；历史导出仍保持三列且消息内容与页面一致。
- 当前自动化环境没有可连接的浏览器实例，因此尚未执行浏览器截图和真实点击回归。
