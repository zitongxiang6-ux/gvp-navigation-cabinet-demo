# GVP 导航与配电箱增强交互 Demo

## 迭代基线

本目录是 REQ-2026-001 至 REQ-2026-004 的唯一当前 Demo 基线。后续同一组需求的交互调整默认直接在本目录继续修改，不另建平行 Demo；只有用户明确要求保留独立版本时才复制新目录。详细约束见 [BASELINE.md](BASELINE.md)。

## 覆盖范围

- Demo 展示层暂时隐藏左侧【首页】和【导航】两个入口；对应页面、路由和实现代码全部保留，可在后续评审需要时恢复。
- REQ-2026-001：导航只保留组件视图；主导航保留独立“配电箱功能查询”，删除“设备功能”菜单、路由页面及专属实现。新查询页将区域树和所选区域下的配电箱/未分类收窄后左右并排，右侧直接展示设备功能明细表格，不显示表格标题或说明文字。
- REQ-2026-002：配电箱及设备/功能关联由其他平台维护并同步；GVP 只读消费同步结果，用于独立配电箱功能查询的区域/配电箱即时筛选、未分类、在线功能点数/总功能点数和功能明细，以及设备管理的只读展示、筛选和导出；不提供配电箱维护或关联写操作。
- REQ-2026-003：历史记录保持三列，只增强设备故障的消息内容，在原故障内容末尾追加 IP 地址；消息中的配电箱名称使用其配置颜色，仅改变字体颜色，不增加图标。
- REQ-2026-004：设备管理右上角不显示“配电箱”入口，不提供清除、新建、管理、选择等写操作；保留配电箱下拉自动筛选、表格末列只读展示和设备导出配电箱字段。

## 启动方式

推荐直接双击 `启动Demo.cmd`。脚本会在后台启动本地服务并自动打开浏览器；重复执行不会重复创建服务。

也可以在 Demo 目录中执行：

```powershell
.\start-demo.ps1 -OpenBrowser
```

或在项目根目录执行：

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory "workspace\demo\REQ-2026-001-004-gvp-navigation-cabinet"
```

然后访问：`http://127.0.0.1:4173/?v=20260831-remove-device-functions#cabinet-functions`

如需关闭后台服务，在 Demo 目录执行：

```powershell
.\stop-demo.ps1
```

## 配电箱功能查询保护基线

- “设备功能”菜单、路由页面和专属实现均不保留；访问旧 `#device-functions` 地址自动进入【配电箱功能查询】。
- 配电箱功能查询的区域树和配电箱选择左右并排且自动生效；右侧无功能操作，直接展示设备功能明细表格，不显示“设备功能明细”标题和筛选说明。

## 技术说明

- 零依赖静态 HTML、CSS、JavaScript，不连接真实接口。
- 所有数据均为脱敏 Mock 数据，只保存在当前页面内存中；刷新页面恢复初始状态。
- 配电箱和设备/功能关联均为外部同步结果的 Mock 快照；Demo 不提供配电箱主数据或关系写入口。
- 配电箱功能查询使用原组件 Mock 数据模拟功能点；独立“设备功能”页面已删除。
- 所有标准列表筛选自动生效，不增加查询或重置按钮。
- 首页和导航仅通过 `is-temporarily-hidden` 隐藏入口；恢复时移除该类名即可，不需要恢复页面代码。
